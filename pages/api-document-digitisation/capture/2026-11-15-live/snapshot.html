Your questions, answered

Parse is Sarvam's document parsing API, built on a 3B parameter state-space vision language model. It extracts text, tables and structure from documents across 23 languages (22 Indian + English) and returns them in reading order.

Parse supports all 22 official Indian languages: Hindi, Bengali, Tamil, Telugu, Marathi, Gujarati, Kannada, Malayalam, Assamese, Urdu, Sanskrit, Nepali, Dogri, Bodo, Punjabi, Odia, Konkani, Maithili, Sindhi, Kashmiri, Manipuri, and Santali, plus English.

Parse accepts PDF, PNG, JPG, and ZIP files (flat archives containing JPG/PNG document pages). Output is delivered as a ZIP file containing the processed document in either HTML or Markdown format.

The Parse API uses an asynchronous job-based workflow: create a job with your desired language and output format, upload your document, start processing, and then download the results. This design handles large documents and batch workflows efficiently.

Parse extracts complex tables, including those with merged cells, multi-level headers, and invisible borders. It preserves row/column structure and outputs clean HTML or Markdown tables ready for downstream processing.

Parse is priced at ₹0.50 per page. Visit the pricing page or API dashboard for the latest details and free tier availability.
