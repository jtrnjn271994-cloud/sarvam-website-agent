# Gap dossier (PROBE)

The hero headline currently reads: "Better code in the long run". The sub-line states: "Coding Agents work across the codebase and saves checkpoints as it goes. The plan stays visible, so you can change direction while the run is live."

This hero fails several buyer needs. It gives no checkable proof points. It does not speak to technical evaluators in GCCs and IT services. The headline does not state clearly what the product does. For the buyer question answered worst, none asked (page questions not approved). The hero also leaves the main objection unanswered: The pilot cannot reach production data. Evaluators must protect client code and require proof of data isolation before testing developer tools.

We hold evidence that Coding Agents creates checkpoints, tests code changes, and keeps repositories within Indian jurisdiction (CL-001, CL-005, CL-008).

If we change the hero message and action button to highlight Indian data jurisdiction and safe refactoring for technical evaluators in GCCs and IT services, more of them click the hero's main button, because technical leaders require data security before they test automated coding tools.

We have no internal analytics, so the real click rate is unknown. An equal or lower click rate on the hero button during testing would prove the hypothesis wrong.
