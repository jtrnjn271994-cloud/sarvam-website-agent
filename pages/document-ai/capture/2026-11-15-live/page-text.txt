Your questions, answered
What is Document AI?
Document AI is Sarvam's set of tools for complex documents. Parse turns pages into text and tables with the layout intact. Extract returns the fields you ask for, each with its page. Classify labels each document by type, and Split breaks bundled PDFs into separate documents.
How does it differ from using GPT, Gemini or Claude directly?
A general AI model reads a document to answer a question. Extract reads it to fill in the fields you asked for. Every value comes back with a confidence score and its page, missing fields stay empty, and accuracy holds on long files. On ExtractBench, Extract Advanced scores 95.43, against 91.91 for GPT-6 Astra on its own, and 91.5 against 31.7 on the longest files.
What does it cost?
Parse is ₹0.50 per page, Extract is ₹1 per page, Classify is ₹0.50 per page and Split is ₹0.75 per page, before tax. Volume discounts apply as usage grows.
How long a document can it process?
Extract processes documents of up to 500 pages in a single job. Each upload can be up to 50 MB.
What happens when a value is not in the document?
It returns empty rather than guessed. Every value also carries a confidence score, so you can accept high-confidence values automatically and route the rest to a reviewer.
Which languages and file types are supported?
English and 22 Indian languages, in print and handwriting. Inputs can be PDF, JPG, PNG or ZIP. Parse returns Markdown, HTML or JSON, and Extract returns JSON, CSV or XLSX.
Where is my data processed? Can it run on our own servers?
Choose Sarvam Cloud, where your data stays in India, run it inside your own cloud account, or deploy it on your own servers. We do not train on customer data, and you control how long files are retained.
Is it only for Indian documents?
No. Extract ranks 5th of 51 on ExtractBench, a public benchmark of 370 enterprise documents, and Parse ranks first on olmOCR-Bench. Indian scripts and handwriting are where its lead is widest.
What is the difference between the API and the platform?
The API is for developers building document processing into their own systems. The platform is a workspace where teams upload documents and review every value before export. Workflows, for chaining steps on one canvas, is coming soon.
