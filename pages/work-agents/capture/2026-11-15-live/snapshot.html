What agents can do

Agents can create sub-agents, act in connected applications, run on a schedule, and use your documents as context.

Use your documents

Add one document or one lakh documents. Agents use them as context when producing work.

Create sub-agents

A lead agent can create sub-agents, give each one a task, and combine their work into one output.

Take action

Connect an agent to Slack, Google Calendar, GitHub, and more than 100 applications. It can send messages, accept invites, and push code updates.

Run on a schedule

Set a daily, weekly, or monthly schedule. The agent runs the task without someone starting it each time.

Build an agent in four steps

  1. 01

    Choose or build an agent

    Start with a ready-made agent or describe the job in plain language. Answer the setup questions to define how the agent should run it.

    Create an agent for my marketing team's monthly media spend report.

  2. 02

    Define what success looks like

    Describe the output you need and the checks it must pass before the agent returns it.

  3. 03

    Teach it your process

    Add the documents the agent should use, connect Notion, Slack, HubSpot, or Google Drive, and set rules for every run. You can require review before publishing, source citations, and your company tone. You can also tell the agent to keep pricing private.

  4. 04

    Share it

    Share the agent with a team or deploy it in Slack.

Turn one team member's process into a shared agent

A team member who owns the monthly report builds the agent and sets its rules. The rest of the team can run it. Deploy the agent in Slack so people can use it in a channel.

Configure each agent

Set which applications and documents the agent can access, the rules it follows, and when it can create sub-agents.

Connectors

Connect Notion, Slack, HubSpot, Google Drive, Linear, GitHub, Jira, and more than 100 other applications. Agents can read data and take actions through those connections.

Skills

Skills set the instructions an agent follows on every task. They can require review before publishing, source citations, and your company tone. They can also tell the agent to keep pricing private.

Sub-agents

A lead agent can divide a job among sub-agents with separate tools and instructions, then return one finished result.

Tasks you can hand off

Each run returns an output your team can review.

Meeting prep

On a schedule, an agent reads your calendar, gathers the context for each meeting, and prepares a brief for the day's meetings.

Monthly reporting

Connect an agent to your ad accounts and analytics. It collects the numbers and writes the monthly report.

Research and slide deck

Give the agent a topic and the required deck format. It researches the topic, drafts the slides, and returns a completed presentation.

Background tasks

Schedule a recurring task. The agent runs it at the set time and returns the output for review.

Deploy to Slack

Deploy an agent in Slack. Ask a question in a channel and receive the answer in the thread.
