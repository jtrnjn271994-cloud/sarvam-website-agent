# Rule book

Draft, 13 Nov 2026. This is the list of rules for the project. Each rule is Keep, Amend or Repeal.

## How to change a rule

1. Write the change in the Amend or Repeal table with a date and a reason.
2. The user approves the change.
3. Update the rule file that holds the rule.
