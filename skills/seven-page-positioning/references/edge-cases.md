# Edge cases

## No rival row for an alternative the buyer names
- Add the alternative with the label UNCHECKED. Write "no rival page read" in `reason`.
- Example: OpenRouter, Bedrock, Azure and Vertex are not opened (context pack section 12).
- Do not claim the swap test passes for it. Write `rival_could_print` true or mark the row UNCHECKED in `reason`.

## The best proof is VENDOR only
- Use it. Keep the label VENDOR. Say in `reason` that Sarvam describes its own offer.
- Do not write "verified". Name the missing independent proof as a weak point.

## The brief is not signed
- Write the position as PROPOSED. Name each open conflict in `self_check.gaps`.
- Do not pick a first buyer or a CTA wording on your own.

## The insight has no buyer id
- Drop the tension. Do not build a claim on it.

## Every rival can print the best claim
- Say so in `weak_points`. Rewrite from the proof. If none works, write `[NEED: differentiator]` in `gaps`.

## A claim needs a number the files do not hold
- Write "not in our research". Do not estimate.

## The position and the live page disagree
- Keep the position. Use `baseline_change` in each bet to say which baseline sections stay, drop, move or are added.
