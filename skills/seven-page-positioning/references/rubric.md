# Rubric: step 3a

Score each criterion 1, 3 or 5. Jev and the reader use it.

| Criterion | 1 | 3 | 5 |
|---|---|---|---|
| First buyer | Two buyers, or a vague "enterprises". | One role, but not copied from the brief. | One role copied from the brief with its id and label. Conflicts listed. |
| Category | Our product name. | A category word, not the buyer's. | The buyer's own word, with a line on what it is not (not GPU rental). |
| Alternatives | Only our rival list. | Buyer alternatives and rivals mixed, no type. | Each alternative typed (direct, secondary, indirect) and sourced to buyer words. |
| Main claim | Restates the page. A rival can print it. | One sentence, but only partly testable. | One sentence, provable true or false, and no rival row can print it. |
| Proof | No ids, or AUDIT used. | Ids exist. One label is too strong. | Every line has an existing id and a label that fits. Limits kept. |
| Swap test | One line for all rivals. | A row for each rival, some without a reason. | A row and a reason for each rival row. Unknowns marked UNCHECKED. |
| Weak points | None, or vague. | Three, but none names a better rival. | Three, specific, one names where a rival is better. |

Pass bar: no criterion below 3. Main claim, Proof and Swap test at 5.
