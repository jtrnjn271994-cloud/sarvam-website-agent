# Glossary

- **Position:** one buyer, one category, the alternatives, one main claim and the proof for it.
- **First buyer:** the one role that decides or starts the purchase for this page.
- **Category:** the word the buyer uses to find a product like ours.
- **Alternative:** what the buyer can do instead of buying from us. It can be a rival, an internal build or doing nothing.
- **Main claim:** the one sentence the page must make true for the buyer.
- **Proof line:** a fact with an evidence id and a label that supports the main claim.
- **Swap test:** ask whether a rival could print the claim word for word. If yes, it is not a position.
- **Rival row:** one competitor or alternative in the rivals file.
- **Bet:** one way a page carries the position, with its own section plan.
- **Evidence id:** the id of a note on file, such as EV-007.
- **Label:** how well a fact is checked: CHECKED, CALC, VENDOR, SEMRUSH, AUDIT, PROPOSED or UNCHECKED.
- **Open conflict:** a choice in the brief that the files leave open, such as two first buyers.
- **Token:** a unit of text that a model reads or writes.
- **API:** the software connection that sends a request and returns a result.
